# 结果评审技能

## 目标

当用户要查看、解释或评审生成结果，尤其是生成的测试用例时，使用这个技能。

## 触发条件

当主意图是 `RESULT_REVIEW` 时使用。

典型请求：

```text
查看 generated_cases.json
这批用例质量怎么样
帮我评审生成结果
生成结果保存在哪里
```

## 输入

```text
结果文件路径
评审目标
生成任务 query
```

## 工作流程

1. 定位结果文件。

2. 解析输出内容。

3. 汇总结果数量和来源信息。

4. 检查结构和质量。

5. 返回发现的问题和建议。

## 输出约定

```json
{
  "file": "...",
  "summary": {},
  "findings": [],
  "suggestions": []
}
```

## 质量检查

```text
字段是否完整
case_type 是否合法
priority 是否合法
source_chunk_ids 是否存在
步骤是否可执行
预期结果是否明确
是否重复
是否覆盖关键场景
```

## 禁止事项

```text
不要只给笼统评价
不要忽略结构性错误
```

## 兜底策略

如果缺少文件路径：

```text
优先尝试 data/generated/generated_cases.json
否则向用户确认文件路径
```

如果 JSON 不合法：

```text
返回解析错误和原始文件路径
```
