# 项目问答技能

## 目标

当用户询问 Tagent 的架构、当前实现、设计原因或下一步时，使用这个技能。

## 触发条件

当主意图是 `PROJECT_QA` 时使用。

典型请求：

```text
这个项目下一步做什么
解释一下意图识别流程
现在完成到哪一步了
这个模块为什么这么设计
```

## 输入

```text
用户问题
相关文件路径
当前项目状态
```

## 工作流程

1. 判断问题是在问架构、实现、流程，还是后续规划。

2. 阅读相关本地文件。

3. 对照当前实现和项目设计。

4. 结合具体文件和当前状态回答。

5. 区分已经完成的内容和仍在规划中的内容。

## 工具

```text
read_file
search_code
git status
```

## 输出约定

```json
{
  "answer": "...",
  "evidence": [],
  "current_status": "...",
  "next_steps": []
}
```

## 质量检查

```text
是否基于当前文件
是否区分已实现和未实现
是否给出具体下一步
是否避免泛泛而谈
```

## 禁止事项

```text
不要把规划说成已实现
不要忽略用户本地修改
```

## 兜底策略

如果本地上下文不足：

```text
先搜索相关文件
明确说明假设
```
